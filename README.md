# Task 1 — E-Commerce Customer Churn Prediction System

A standalone Streamlit portfolio project for customer churn analytics and machine learning.

## What it covers
- Data cleaning and data-quality audit
- Exploratory analysis and churn-rate analysis
- Numerical/categorical preprocessing
- Missing-value handling and one-hot encoding
- Class imbalance using class-weighted models
- Multiple classification models
- Precision, recall, F1, ROC-AUC and PR-AUC
- Confusion-matrix-ready predictions
- Threshold optimization through the dashboard
- Permutation feature importance
- Customer-level churn probability and Low/Medium/High risk
- Downloadable scored customer file
- Practical retention recommendations

## Run
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

A demo dataset is included at `data/customer_churn_demo.csv`. For a formal submission, upload a real public e-commerce/customer-churn dataset through the portal and document its source in your project report.
